# Mission 0 — Create Your GitHub Workspace

## 1. Task / objective

The objective of this mission was to create a properly organised GitHub workspace for the Digital Detective assignment. This included setting up a local project folder, creating the required mission folders and files, preparing the root README, and publishing the project to a public GitHub repository.

## 2. Work completed

- Created the local project folder named `digital-detective-8080`.
- Opened the project folder in VS Code and Terminal.
- Prepared the root `README.md` with the project title, description and mission index.
- Prepared the workspace structure for the upcoming missions.
- Started setting up the GitHub repository.

**Repository name:** `digital-detective-8080`

## 4. My understanding

I understood how a local project folder and a remote GitHub repository work together. A local repository allows me to manage and track changes on my computer, while GitHub provides an online platform to store and share the project.

I also learned that a well-organised folder structure makes it easier to manage different missions independently. The README file acts as documentation for the project and helps others understand its purpose and organisation.

## 5. Difficulties faced

- Encountered a divergent branches error while trying to pull changes from GitHub.
- Encountered an unrelated histories error when attempting to merge the local and remote repositories.

## 6. How I resolved them

After understanding the Git errors, I decided to create a fresh GitHub repository instead of merging the independently created repository histories.

This approach will allow me to connect my existing local project to a new remote repository.

**Status:** New repository setup and connection are still in progress.
