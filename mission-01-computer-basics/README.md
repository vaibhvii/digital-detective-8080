# Mission 1 — Know Your Computer

## 1. Task / objective

The objective of this mission was to understand how a computer receives input, processes information, produces output and stores results using the IPOS cycle. It also involved identifying hardware and software components and exploring computer-based systems used in everyday life.

## 2. Work completed

### Task 1.1 — Trace one activity using IPOS

**Chosen activity: Typing and saving a document**

The IPOS cycle explains how a computer handles information through four stages: Input, Processing, Output and Storage.

| Stage | What happens? | Hardware / component |
|---|---|---|
| Input | I type text using the keyboard. | Keyboard |
| Processing | The computer processes the entered text and handles the instructions from the application. | CPU and RAM |
| Output | The typed text appears on the screen. | Monitor / Display |
| Storage | The document is saved so that it can be accessed later. | SSD / Storage drive |

### Task 1.2 — Identify hardware and software

**Hardware components**

Hardware refers to the physical components of a computer that can be touched.

| Item | Classification | Software type | Purpose |
|---|---|---|---|
| Keyboard | Hardware | Not applicable | Used to enter text and commands. |
| Mouse / Trackpad | Hardware | Not applicable | Used to interact with the computer. |
| Monitor | Hardware | Not applicable | Displays visual information. |
| SSD | Hardware | Not applicable | Stores files and data. |

**Software examples**

Software refers to programs and instructions that allow a computer to perform different tasks.

| Software name | Classification | Software type | Purpose |
|---|---|---|---|
| macOS | Software | Operating system | Manages computer hardware and resources. |
| Google Chrome | Software | Application software | Used to browse the internet. |
| Visual Studio Code | Software | Application software | Used to write and edit code. |
| Disk Utility | Software | Utility software | Used to manage and check storage devices. |

### Task 1.3 — Computer systems around you

Computer-based systems are used in everyday life to perform specific tasks by accepting inputs and producing outputs.

| System | Main purpose | One input | One output |
|---|---|---|---|
| ATM | Allows users to perform banking transactions. | Card / PIN | Cash or transaction receipt |
| Smart TV | Provides entertainment and displays digital content. | Remote control input | Video and audio |
| Traffic signal | Controls the movement of vehicles and pedestrians. | Timer / Sensor input | Traffic lights |

## 4. My understanding

Through this mission, I understood that a computer works through the coordination of hardware and software.

The IPOS cycle explains the basic working process of a computer. Input provides data, processing handles that data, output presents the results, and storage saves information for future use.

I also learned the difference between hardware and software. Hardware consists of physical components, whereas software consists of programs and instructions that control or use those components.

Software can be classified into operating system software, application software and utility software depending on its purpose.

Finally, I understood that computer-based systems are not limited to laptops and mobile phones. Devices such as ATMs, smart TVs and traffic signals also use computing systems to perform everyday tasks.
